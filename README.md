## 🔍 En qué trabajo

- 💻 **Desarrollo Full Stack:** construcción de aplicaciones web completas, desde el Frontend hasta el Backend y la base de datos.
- 🎨 **Frontend:** desarrollo de interfaces modernas, responsive y basadas en componentes utilizando Angular, Astro y TypeScript.
- ⚙️ **Backend:** creación de APIs y servicios utilizando Python, Flask y FastAPI.
- 🗄️ **Bases de datos:** diseño, consultas y administración de bases de datos SQL.
- 🔐 **Autenticación:** implementación de sistemas de autenticación y control de acceso.
- ☁️ **Despliegue:** configuración y publicación de aplicaciones utilizando servicios cloud como AWS, Vercel y Netlify.
- 🐳 **Contenedores:** uso de Docker para entornos de desarrollo y despliegue.
- 🔧 **Soporte y plataformas:** administración de plataformas empresariales, configuración de dispositivos MDM y atención de requerimientos tecnológicos.
- 📋 **Requerimientos:** comunicación con clientes y usuarios para entender necesidades y convertirlas en soluciones técnicas.
